# Foundation decisions — 2026-10-25

1. **Node 24 LTS + npm workspaces.** Local runtime: v24.19.0 / npm 11.17.0. Node's [release table](https://nodejs.org/en/about/previous-releases) identifies 24 as LTS. The lockfile pins resolved packages. React 19, Vite 8 and Vitest 5 compatibility is assessed through recorded builds/tests.
2. **Built shared ESM.** `@aq/contracts` exports JS and declarations from `dist`; browser, tsx, compiled Node and tests use the same public import. Root consumer scripts build it first. No source aliases or dual CommonJS package. Contracts are watched in development.
3. **Small Express boundary.** The factory injects DB health and has no side effects. Startup validates config, creates a lazy pg pool and binds loopback; no provider/DB query. Health requests probe only PostgreSQL with bounded connection/query timeouts. HTTP 200 describes service liveness; DB and data readiness have separate statuses. No provider adapter/cache.
4. **Guarded pg migrations.** Loopback, two project database names, no URI query overrides, explicit ownership confirmation. Fixed `aq_workbench` schema; existing schemas require a project marker. Transaction/advisory lock, checksum/history checks and rollback. Parameterized runtime values. Application migrations create no roles/databases and require no elevated rights. Explicitly authorized infrastructure provisioning creates restricted roles and two project databases in the new dedicated container. No extensions, PostGIS, data drops or resets.
5. **Separate scientific products.** Sites/reporting areas have separate observation schemas; forecasts/contours have their own contracts. AQI/concentration have compatible explicit units. Raw values and qualifiers survive normalization. No clipping, implicit conversion or AQI calculation.
6. **Truthful shell.** Four planned routes and no AQI readings. Mode comes from validated health. Every mode is unavailable until data loading exists. Synthetic JSON is a test fixture, not a hidden fallback.
7. **Deterministic verification.** Default tests need no provider credentials/DB. DB integration is separate and opt-in; CI provisions only its own ephemeral PostgreSQL. Local setup uses the user-authorized dedicated PostgreSQL 18 container on the existing Docker Engine; other containers remain untouched. Remote CI has not been run.

The four PNG references were absent. This milestone builds a minimal responsive shell without claiming to match unseen designs. Existing prompt documents are unchanged.
