# V1 limitations and follow-up

| Item                                                                | Current behavior / consequence                                                                                                                                   | Priority                                           |
| ------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------- |
| AirNow live / official area forecasts                               | Production wire codecs unverified; unavailable. Keys do not establish integration. Retired routes are not enabled.                                               | P1 expansion, not required for explicit local demo |
| Authenticated AQS ingestion                                         | Not implemented. Eaton uses public AirData artifacts; certification remains unknown.                                                                             | P1                                                 |
| Basemaps                                                            | Internet and permitted public ArcGIS token required. Keyless fallback preserves data inspection, without tiles. User account must restrict referrers/privileges. | P1 external dependency                             |
| Historical coverage                                                 | One 72-slot Eaton window / 71 rows / one monitor. GIS layers are documented repaired/clipped derivatives. No full LA archive or automatic refresh.               | Deliberate scope                                   |
| Perimeter/hazard dates                                              | Static archived perimeter; LRA recommendations postdate ignition; local adoption unknown.                                                                        | Scientific constraint                              |
| 3D, contours, smoke/wind, separate elevation and source attribution | Disabled/unavailable. No verified risk, causality or exposure claims.                                                                                            | P1 / outside scope                                 |
| Accessibility/browser breadth                                       | Chromium plus named keyboard/focus/responsive checks; no full WCAG certification, Firefox/WebKit or screen-reader audit.                                         | P1                                                 |
| Large SDK chunks                                                    | ArcGIS is lazy loaded, but build warns of chunks over 500 kB. No formal latency budget/low-end-device benchmark.                                                 | P1                                                 |
| Usage                                                               | In-memory since-start counters; excludes browser ArcGIS, billing and distributed aggregation.                                                                    | Deliberate scope                                   |
| Storage                                                             | Capacity refusal instead of deletion. No automatic pruning, backup or restore workflow.                                                                          | Local PoC scope                                    |
| Deployment / AI                                                     | No public hosting, application authentication, LLM/RAG or Prompt 11/12 dependency. Reviewed target is loopback-only.                                             | Outside Core V1                                    |

The [freeze review](../milestones/10-v1-freeze-review.md) records current P0 status and local/remote evidence. These limitations do not waive scientific correctness or secret-exposure failures. Future implementation changes require fresh verification.
