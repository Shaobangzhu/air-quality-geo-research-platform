# Wildfire Case Study — Prompt 08

`/wildfire` is the only event page. Navigation opens the curated historical Eaton case; explicit `mode=live` or `mode=sample` is unavailable with an explicit historical-opening action. No monitoring-site or reporting-area request is issued while the case is active. There is no synthetic wildfire case. `/data?case=eaton-fire-2025&mode=historical` exposes this case's methods and citations within the existing Data page; this is not the complete export/metrics milestone.

The BFF `GET /api/wildfire/eaton-fire-2025?mode=historical` lazily reads the versioned local manifest, validates SHA-256 of each artifact, validates layer identities/classifications/bounds, normalizes the EPA rows through the existing import contract and returns an immutable in-process case. Failure returns an explicit BLOCKED response; no provider or database fetch is needed on page launch. Query ambiguity/unknown fields are rejected. The reviewed source files and committed hashes are a trust boundary, not a claim of cryptographic publisher signatures.

51 feature graphics (one perimeter, 31 SRA, 19 LRA) use three reused GraphicsLayers in the existing ArcGIS map runtime. One monitor is a blue location symbol, never an AQI-colored hazard marker. Source GeoJSON has counterclockwise outer rings/clockwise holes; rings reverse on ArcGIS Polygon ingestion. Layers are allocated only for the case and retain geometry when visibility or timeline changes. One component-owned map/view is disposed at unmount; no new view for selection, filters or toggles. Topographic relief supplies terrain context. Basemap loading failure leaves all metadata and records accessible in native controls.

Map hit tests select a contextual feature, with monitor precedence. Keyboard users can select every visible feature from a native select. Hiding a layer clears selection. The timeline selects Jan 6, Jan 7 or Jan 8 records and a PST hour; it never changes the static perimeter. Jan 7 is an ignition-day context spanning hours before and after ignition, not a precise start-time animation. Jan 8 is a later checkpoint during the incident, not post-fire. There are no charts, modeled plumes or risk scores here.

The monitor's Jan 8 05:00 PST slot is absent. Show “Missing observation”; do not create a zero/interpolated row. Measurement value/unit, GMT source timestamp, averaging period, method, source qualifier and last-change date remain traceable. Historical AQS provenance is separate from per-row certification (`unknown`). IT/IJ qualifiers are displayed literally, not promoted to a causal finding.

SRA effective date: April 1, 2024. LRA: 2025 recommendations published after ignition; local adoption/effective date unknown. FHSZ is long-term hazard; unmapped is not Low. The perimeter is firep25_1, released April 2026, and uses a documented display topology repair. Source attribution and limitations remain accessible below the map and in the Data page. Optional 3D, AirNow contours and smoke/wind are visibly unavailable, never phantom layers.

Local assets total about 1.2 MB uncompressed, versus large nationwide/statewide downloads retained only in ignored `.local/milestone08`. The schema caps each artifact at 2 MB, source features at 100 per layer, combined features at 150, and vertices at 60,000. No raw archive, key, signed URL or source token enters the browser bundle.
