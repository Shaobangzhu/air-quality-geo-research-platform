# Development rules

Product: Greater LA Air Quality Geo Research Platform. This is a local-first interview research PoC. Read README.md and the current milestone before changing behavior. Existing numbered prompt documents are reference material, not authorization to implement all milestones.

- Use Node 24 LTS, npm workspaces, strict TypeScript, React/Vite and Express. `packages/contracts` has shared Zod schemas with built ESM/type exports; build it before consumers. Keep the app factory separate from startup.
- Keep the four-page IA: `/map`, `/analysis`, `/wildfire`, `/data`. `/` shows the Map Explorer shell. No dashboard, AI, research-notes or settings routes in Core V1.
- Inspect git status first; preserve user changes and existing data. Do not commit/push unless instructed. Do not modify unrelated containers/volumes or query unrelated databases. The user explicitly authorized creating `air-quality-geo-research-platform-postgresql` and its dedicated network/volume on 2026-10-25; `cpi-postgres` belongs to another project and must remain untouched. Any additional infrastructure needs explicit authorization.
- Local PostgreSQL is user-managed. Only connect to an explicitly confirmed project database (`air_quality_geo_research` or `air_quality_geo_research_test`) on loopback. Use the dedicated `aq_workbench` schema. Never guess credentials. Missing PostgreSQL is a documented blocker.
- Migrations are append-only SQL with checksums, a transaction and an advisory lock. Refuse adoption of an unmarked schema. Do not modify applied migrations, reset/drop data, or add privileged role/database creation to the app. Parameterize runtime values.
- AQI and concentration are distinct. Keep raw values (including small negative measurements), nullable missing values, units, period meaning, source identity and UTC timestamps. Monitoring sites and reporting areas differ; forecasts and contours need separate contracts. Old AirNow records are not automatically validated AQS data.
- `sample` is explicitly synthetic, `historical` requires official snapshot provenance, `live` requires a real provider. `unavailable` is a state. No fake live values or implicit fallbacks. Synthetic fixture IDs start with `SAMPLE-`.
- Keep credentials server-only, except a deliberately public, browser-restricted ArcGIS credential. Never log connection strings, raw configuration errors, signed URLs or provider keys. Ignore real env files, dumps and build/test outputs.
- Provider smoke verification requires `ALLOW_LIVE_API_TESTS=true`; the current gate refuses live access until a reviewed wire codec exists. Default tests, builds and UI work without keys. DB integration additionally requires `ALLOW_DB_TESTS=true` and the separate test DB.
- Verify official provider contracts before implementing adapters. The six legacy AirNow routes listed in the capability document are forbidden. Use current ArcGIS components when mapping is introduced; recheck version support then.
- Run lint, typecheck, unit tests, build and browser smoke. Run DB integration only against a confirmed test database. Report unrun checks honestly; configured CI is not remotely verified CI.

Milestone 04: see `docs/frontend/station-observations.md` and `docs/milestones/04-station-observations.md`. Milestone 05: see `docs/frontend/map-interactions.md` and `docs/milestones/05-linked-interaction.md`. Three rectangular engineering presets share Greater LA batch acquisition/cache; snapshot identities retain their original parent coverage. Milestone 06: see `docs/frontend/analysis-series.md` and `docs/milestones/06-analysis-time-series.md`. Analysis owns all full series charts. Use one bounded `/api/analysis-series` read for up to three identities, with 24/48/72 UTC slots; absent/null/outside-coverage/conflicting slots are gaps, not observations. Only explicit consistent hourly boundaries and source units/interpretations permit lines/comparison. Preserve record provenance, local DST labels plus UTC, and Map primary identity. Historical partial windows mark source coverage without changing stored data. Recharts is lazy loaded; inspection never fetches. No production AirNow codec or new DB infrastructure was added.

Milestone 07: see `docs/frontend/reporting-area-products.md`, `docs/data-sources/airnow-area-products-verification.md` and `docs/milestones/07-reporting-area-products.md`. Reporting-area aggregates and forecasts have independent strict records/services/cache; neither is a station or concentration. Only explicitly synthetic sample alternatives are enabled. Official codecs/geometry and historical archive remain unavailable; no flag bypasses the missing codec. Keep the station layer invisible/empty during area modes on the same view; do not infer centroids or polygons. Forecast date-only validity/unknown issuance stays unexpanded. Do not claim official-product acceptance from mock/sample evidence.

Milestone 08: see `docs/milestones/08-wildfire-case-study.md`, `docs/data-sources/eaton-case-feasibility.md` and `docs/frontend/wildfire-case.md`. Eaton is an official historical-only local case, not a sample/live fallback. Preserve checksummed artifact bytes and immutable case/snapshot manifests. Do not edit applied migration 003. Distinguish Jan 6–8 study coverage from Jan 7–31 incident dates, static firep25_1 (April 2026) from progressive perimeters, 2024-effective SRA from later 2025 LRA recommendations, and FHSZ hazard from risk. Display topology repairs/clipping are documented derivatives. Preserve EPA POC/method, UTC/local timestamps, raw qualifiers and revisions; historical AQS row certification remains unknown. Optional 3D/contours/smoke stay unavailable without independent verification.

Milestone 09: see `docs/milestones/09-data-methodology.md`, `docs/frontend/data-methodology.md` and `docs/architecture/data-exports.md`. `/data` has four internal tabs, one visible panel. Reuse existing strict sample/historical readers; live exports remain unavailable. Preview/export caps are 10 preview rows, 500 selected records, 3 MB and four concurrent operations. Exports require the preview selection hash; CSV has one embedded manifest row then data rows, null `\N`, spreadsheet hardening and lossless `record_json`. Preserve source status/version uncertainty, qualifiers and revisions. HTTP attempts count at actual send, completed outcomes plus in-flight equal attempts, and latency uses completed attempts. Cache metrics cover instrumented station/area TTL caches, excluding curated file memoization/browser/DB caches; ArcGIS client traffic and billing remain outside local metrics. No database schema, applied migration, provider codec or infrastructure change was introduced.
